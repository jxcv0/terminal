# AI contribution policy

These instructions apply to all AI agents working in this repository.

- Do not write, modify, or delete code unless the user specifically asks for code
  changes. Requests for analysis, advice, review, or planning do not authorize
  code contributions.
- When code changes are explicitly requested, make the smallest focused change
  necessary to fulfill the request. Keep the scope and diff minimal so a human
  can readily understand, review, and approve the work.
- Avoid unrelated fixes, refactoring, formatting changes, dependency changes,
  and new abstractions. Broader changes require an explicit user request.
- Prefer straightforward, readable solutions that are easy for a human to
  follow.
- Explain what changed, why it was necessary, and how it was verified. Clearly
  identify any limitations or remaining work relevant to the request.
